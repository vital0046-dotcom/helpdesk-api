# Как показать проект преподавателю

1. Открой ярлык «Helpdesk — показать проект». Если окно осталось открытым с прошлого запуска, закрой его и открой заново, чтобы загрузить обновление.
2. Оставь режим «Локально · SQLite · без интернета». Окно редактора оставляй открытым: оно сейчас держит общий API.
3. Нажми «Пройти показ целиком (01–11)». Выбирай строки в таблице, чтобы показать отправленный JSON и ответ.
4. Расскажи: «Это сервис заявок в техподдержку на Python и Flask. Клиент отправляет HTTP-запросы, сервер проверяет данные, SQLAlchemy работает с базой. Есть связанные таблицы пользователей, категорий, заявок и комментариев».
5. Покажи создание заявки (201), фильтрацию (200), запрет закрыть новую заявку (409), взятие в работу, комментарий, закрытие и статистику.
6. Нажми «Редактировать данные» или открой ярлык «Helpdesk — редактировать заявки». Выбери заявку в таблице, измени название или приоритет и нажми «Сохранить». Для комментариев есть отдельная кнопка.
7. Для новой заявки сначала создай пользователя и категорию на соответствующих вкладках. Затем «Заявки» → «Новая запись» → заполни поля → «Создать».

Что отвечать на вопросы:
- GET читает, POST создаёт, PATCH изменяет, DELETE удаляет.
- Статусы: новая → в работе → закрыта. Закрытую можно вернуть в работу.
- 409 на шестом шаге ожидается: это проверка бизнес-правила.
- В локальном показе SQLite; конфигурация хостинга рассчитана на PostgreSQL.
- Ключ X-API-Key ограничивает доступ к API. Это учебная общая авторизация, отдельных ролей сотрудников нет.
- Тесты: 36 успешно прошли 02.11.2026. Проверяют API, ошибки, связи и сценарий демонстрации.
- Код: helpdesk/routes.py — запросы, models.py — таблицы, validation.py — проверки, tests — тесты.
- Окна демонстрации и редактирования — клиенты настоящего API, а не имитация ответов.

GitHub: https://github.com/vital0046-dotcom/helpdesk-api

Для редактирования кода открой папку helpdesk-api в VS Code через «Файл → Открыть папку». После изменения Python-кода закрой оба окна Helpdesk и запусти заново.

Postman: файлы подключения подготовлены в instance/postman. Во вкладке редактора «Подключение / Postman» есть адрес, копирование ключа и инструкция импорта. Автоматическая настройка браузера заблокирована разрешением; подключение в Postman не подтверждено. Для защиты используй локальный клиент. Доступность Render сейчас не подтверждена.
