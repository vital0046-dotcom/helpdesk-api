## Первичная локальная проверка

Проверено локально 30 октября 2026 года: Windows, Python 3.13.12, SQLite.

- pytest: 33 теста пройдены. Проверены CRUD, фильтры, пагинация, статусы,
  комментарии, целостность связей, ошибки JSON, API-ключ, демоданные и обработчик логов.
- `ruff check .`: замечаний нет.
- `pip check`: конфликтов установленных зависимостей нет.
- Миграция применена, демонстрационные данные созданы; `flask --app wsgi db check`
  не обнаружил расхождений между моделями и схемой базы.
- Waitress запущен на `127.0.0.1:8000`. Все 14 запросов из коллекции Postman
  воспроизведены через HTTP скриптом `python -m tools.smoke_postman`.
  Сценарий создаёт собственные демонстрационные записи и удаляет их в конце.
  В дальнейшем скрипт расширен для чтения API_KEY из окружения или локального env-файла.
- `docker compose config --quiet`: конфигурация корректна.
- Анализатор обработал 5000 записей примера: оба алгоритма дали одинаковые
  количества запросов. Единичный замер: вложенные циклы 0,5419 мс,
  словарь 0,3360 мс. Это пример измерения, не универсальный коэффициент ускорения.

Локальный Docker Engine не запущен: сборка контейнера и PostgreSQL здесь не проверены.

миграции PostgreSQL, проверка стиля и сборка Docker на Linux / Python 3.13.
