# План практики и защиты

Тема: разработка REST API сервиса обработки заявок технической поддержки на языке Python.
Цель: реализовать хранение и обработку заявок с проверкой корректности данных,
связанной базой, автоматическими тестами и воспроизводимым запуском.

## Этапы и материалы

| Этап | Что изучить и выполнить | Материал проекта |
|---|---|---|
| Подготовка | venv, pip, freeze, функции, классы, файлы, Git | requirements, модели, docs/GIT.md |
| Алгоритмы | вложенные циклы, словарь, сложность, замер времени | tools/analyze_logs.py |

| Развёртывание | Docker, PostgreSQL, Gunicorn, nginx, хостинг | Dockerfile, compose.yaml, docs/DEPLOY.md |

## Структура отчёта

1. Введение: цель, задачи и предметная область.
2. Анализ требований: пользователи, заявка, статусы, ограничения первой версии.
3. Проектирование: схема базы, связи и контракт API.
4. Реализация: фабрика приложения, ORM, проверки данных, обработка ошибок.
5. Анализ логов: два алгоритма, оценки сложности, реальные замеры.
6. Тестирование: команды, фактические результаты, примеры ошибок.
7. Развёртывание: выполненные действия, адрес опубликованного проекта.
8. Заключение: полученный результат, ограничения и дальнейшее развитие.
9. Источники и приложения: репозиторий, Postman, примеры запросов.

Даты, место практики, ФИО, группу, руководителя и результаты внешнего деплоя нужно
заполнить по фактам. Шаблон отчёта не является доказательством выполнения этапа.

## Сценарий демонстрации

1. Запустить API и показать /health.
2. Создать автора и категорию; показать их ID.
3. Создать заявку и получить 201.
4. Показать список с фильтром и пагинацией.
5. Попробовать new -> closed: получить 409 и объяснить правило.
6. Перевести в in_progress, оставить комментарий, закрыть заявку.
7. Показать статистику и тесты.
8. Запустить анализатор логов и объяснить отличие O(n*k) от O(n).
9. После публикации повторить запросы на адресе хостинга с API-ключом.

Для учебной демонстрации используются вымышленные данные. Общий ключ не заменяет
раздельные роли пользователей и сотрудников; это одно из направлений развития.
